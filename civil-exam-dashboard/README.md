# 双考备考驾驶舱

一个面向国考和江苏省考的本地网页工具。不安装第三方依赖；数据保存在本机服务端，并在浏览器保留副本。

## 启动方式

在 PowerShell 中进入本目录，运行：

```powershell
.\start.ps1
```

脚本会自动选择可用端口并打开浏览器。默认地址为：

```text
http://127.0.0.1:8080/
```

如果系统限制脚本执行，可以使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

也可以直接双击 `index.html` 使用，但建议通过启动脚本访问，以确保浏览器数据保存稳定。

## 手机和平板使用

桌面已经创建“启动手机访问模式”快捷方式：

1. 双击“启动手机访问模式”。
2. 第一次运行时，Windows 防火墙询问时允许“专用网络”。
3. 服务窗口会显示类似 `http://192.168.x.x:8080/` 的地址。
4. 手机或平板连接同一个 Wi-Fi，用浏览器打开该地址。
5. 手机、平板和电脑会共用服务端保存的学习数据。

也可以在 PowerShell 中手动运行：

```powershell
.\start.ps1 -Lan
```

共享模式只适合在可信的家庭或私人网络中开启。不要在公共 Wi-Fi 下长期开启。

## 已实现功能

- 国考、江苏省考报名与笔试节点倒计时。
- 行测基线、目标分、学习时长和错题积压统计。
- 学习路线页：六个模块的方法、每日题量、每周节奏、错题处理和江苏专项侧重。
- 不同题型方法库：按题型给出识别标志、具体做题步骤、公式/判断规则、常见陷阱和专项练法。
- 名师视频搜索入口：推荐区域放在模块页最前面，按模块给出常见公开课程关键词并链接到视频平台搜索页。
- 专项训练记录：记录模块题量、正确数、用时和正确率。
- 专注计时器：支持 25、45、60 分钟，完成后自动记录一次专注训练。
- 本模块今日任务：可以直接在学习路线中勾选当天相关任务，不必来回切换页面。
- 我的方法卡：按模块保存自己的易错点、公式和提醒，并支持一键复制。
- 一键开始本模块专注：按模块建议时长建立计时任务，自动跳到执行计划。
- 方法卡、今日计划和错题复习清单支持打印，方便离开电脑学习。
- 手机和平板共享模式：同一 Wi-Fi 下可访问电脑端服务，并使用同一份学习数据。
- 每日自动生成学习计划，支持按日期勾选完成。
- 自定义任务与每周执行模板。
- 五个行测模块的套卷正确率记录。
- 行测分数趋势图和最新模块分析。
- 自动识别最弱两个模块。
- 错题本、错因筛选和 2、4、7、14、30 天间隔复习。
- 候选岗位收藏与专业核验清单。
- 设置修改、JSON 数据导出和导入、二次确认清空。
- 响应式布局，支持桌面和较窄窗口。

## 首次使用建议

1. 打开“设置”，按官方公告修改两个考试日期。
2. 完成一次限时行测真题，记录总分和五个模块正确率。
3. 回到“总览”查看倒计时、弱项和今日计划。
4. 每天在“执行计划”中勾选完成任务。
5. 错题优先记录错因和知识点，不只是一段题干。
6. 每周至少保留一次真实套卷记录，并导出一次 JSON 备份。

## 学习路线怎么用

进入“学习路线”后，先按顺序选择一个模块，再按页面顺序执行：

1. 先看“核心方法”，确认这类题应该按什么顺序做。
2. 看“阶段节奏”，明确当前是先看课、专项刷题还是限时冲刺。
3. 按“每周节奏”安排次数，不要一天换一个方法。
4. 每次专项训练后，在右下角记录题量、正确数和用时。
5. 点击“名师视频搜索入口”打开搜索页，筛选后固定跟一套课程。

建议每个模块只选一位老师，至少跟完一轮基础方法；同时看多位老师容易造成方法混乱。页面中的老师名称是公开课程搜索关键词，不代表平台推荐或长期课程承诺。

在执行计划页可以使用专注计时器。开始前选择 25、45 或 60 分钟，完成一轮后系统会记录一次专注训练。

如果浏览器仍显示旧版本，请在页面按 `Ctrl+F5` 强制刷新。页面资源已经加入版本号，更新后会自动加载新版内容。

学习路线页顶部可以直接：

1. 点击“开始本模块专注”，按该模块建议时长开始计时。
2. 勾选“本模块今日任务”，完成后状态会同步到执行计划。
3. 在“我的方法卡”记录自己的错题提醒和公式。
4. 点击“打印本模块方法卡”，打印后离线复习。

## 数据说明

- 数据默认保存到 `data/state.json`，浏览器本地存储键为 `civil-exam-dashboard-v1`。
- 数据不会自动上传到互联网，但共享模式下同一局域网设备可以读取和修改数据。
- 清理浏览器站点数据不一定清空服务端记录，可通过“清空全部数据”统一删除。
- 更换浏览器或电脑前，请先导出 JSON。
- 导入会覆盖当前本机数据，操作前会要求确认。

## 文件结构

```text
index.html   页面结构
styles.css   样式与响应式布局
app.js       状态、计划、统计和本地存储
server.py    本地静态服务和共享数据接口
routes.js    六个模块的方法总览和老师搜索关键词
route-details.js       言语、判断详细题型方法
route-details-more.js  资料、数量详细题型方法
route-details-final.js 常识、申论详细题型方法
start.ps1    本地启动脚本
README.md    使用说明
```

## 开发约束

- 原生 HTML、CSS、JavaScript。
- 不安装 npm 依赖或 Python 第三方包。
- 服务端只使用 Python 标准库。
- 不使用在线字体、图标或 CDN。
- 修改后使用 `node --check app.js` 检查脚本语法。
